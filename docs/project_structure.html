Common Problems & Fixes

ProblemFix
ModuleNotFoundError: appSet $env:PYTHONPATH="path\to\kiro\backend;path\to\kiro"
Generation times outSet GENERATION_TIMEOUT_SECONDS=600 in .env
"Cannot reach backend" in UIStart backend first. Check port 8080 is running.
PDF returns 503pip install xhtml2pdf==0.2.16
Tests: NetworkAccessAttemptedCorrect! Socket guard blocks network. Mock the call with respx.
UnicodeEncodeError in scripts$env:PYTHONIOENCODING="utf-8"
npm install failsCheck Node version: node --version (need 18+)
pip fails on WindowsInstall "Visual Studio Build Tools" (C++ compiler)
Ollama not connectingRun ollama serve. Check OLLAMA_BASE_URL=http://localhost:11434
.env not loadingRemove stale env vars: Remove-Item env:GROQ_API_KEY -ErrorAction SilentlyContinue
/health shows "degraded"Normal if keys are missing. System still works via fallback.
